Encrypted Chat

Private rooms where the server only ever holds ciphertext. AES and RSA are written from scratch in this project, with no crypto library.

This page isn't on localhost or https, so the browser blocks the microphone and camera. Run python serve.py and open http://localhost:8000.

Both are stretched together in your browser. Anyone with the same pair lands in the same room, and nobody else can see it exists.

Rooms keep an encrypted history so it's there when you come back. A secretary can read a room's archive, including edited and deleted messages and photos. When that's switched on, everyone in the room sees a notice.

Waiting
  1. 1Your browser hunts two 512-bit primes with Miller-Rabin and builds a keypair. The private half never leaves this tab.
  2. 2The room ID and password are stretched into a room hash and a wrapping key. The server receives the hash and nothing else.
  3. 3The room's session key is unwrapped with your password, or minted if the room is new. A member already online can also hand it over, wrapped with your public key.
